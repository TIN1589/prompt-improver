🔐 Cấu hình Google AI Studio API Key (Mã hóa Local)

Lấy API Key miễn phí tại aistudio.google.com/app/apikey.

Lưu ý: Mật khẩu này không được lưu ở bất kỳ đâu. Bạn sẽ cần nhập lại khi gọi API từ popup.
